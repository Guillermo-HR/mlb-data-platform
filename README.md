# mlb-data-platform

## Español
### Objetivo
El objetivo de este proyecto es crear una plataforma de datos para la MLB, donde se tengan datos históricos y actuales de los equipos, jugadores y juegos. 

### Tecnologías utilizadas
- Python
- Databricks

### Estructura del proyecto
- data_engineering: Contiene la configuracion y scripts para la ingesta y procesamiento de datos.
